Código de Inyección para Moodle 5.0.6+ (Tema Academi)

Listo para pegar en Administración del sitio > Apariencia > HTML Adicional sin modificar archivos .php.

1. Dentro de HEAD (additionalhtmlhead)

<link href="https://fonts.googleapis.com/css2?family=Montserrat:wght@400;500;700;800&display=swap" rel="stylesheet">
<style>
  :root {
    --mype-primary: #342AD8;
    --mype-indigo: #384293;
    --mype-turquoise: #0CBA97;
    --mype-mint: #66BFB2;
    --mype-cloud: #F4F6FB;
  }
  body { font-family: 'Montserrat', sans-serif !important; background: var(--mype-cloud) !important; }
  /* Ocultar barra superior roja de Academi y enlaces Área personal / Mis cursos */
  .header-top, .primary-navigation a[href*="/my/"], .primary-navigation a[href*="/course/"] { display: none !important; }
  /* Depurar menú desplegable de usuario (dejar solo Perfil, Calificaciones, Mis Certificados y Cerrar sesión) */
  #usermenu-carousel a[href*="blog"], #usermenu-carousel a[href*="notes"],
  #usermenu-carousel a[href*="plan"], #usermenu-carousel a[href*="report"] { display: none !important; }
</style>

2. Antes de cerrar BODY (additionalhtmlfooter)

<script>
document.addEventListener('DOMContentLoaded', function() {
  // Expandir los 3 acordeones en Registro (/login/signup.php)
  if (window.location.pathname.includes('/login/signup.php')) {
    document.querySelectorAll('fieldset.collapsible').forEach(el => el.classList.remove('collapsed'));
  }
  // Etiqueta clara de DNI en Login y Recuperación
  const lblUser = document.querySelector('label[for="username"]');
  if (lblUser) lblUser.textContent = 'Número de DNI (o usuario)';
});
</script>
